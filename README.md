# Special Anniversary Interactive Script ❤️

โปรเจกต์สคริปต์ interactive น่ารักๆ สำหรับตอบคำถามและฉลองครบรอบ 2 ปี

## 📌 คุณสมบัติของโปรแกรม (Features)
1. ระบบระบุตัวตน (รับชื่อผู้ใช้งาน)
2. ระบบตรวจสอบรหัสผ่านความปลอดภัย
3. คำถามทดสอบความรักและทางเลือกคำตอบ
4. ระบบ ตรวจสอบวันเกิดแฟน
5. แสดงข้อความแสดงความรักครบรอบ 2 ปี

## 🚀 วิธีการใช้งาน (How to run)
สามารถรันไฟล์ผ่าน Terminal หรือ Command Line ด้วยคำสั่ง:
```bash
python main.py
